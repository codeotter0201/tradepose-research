方法論

一個策略怎麼一層一層長出來？從原始訊號、濾網到延遲進場、停損停利與保本的父子關係

策略研究常見的做法，是把訊號、濾網、進場、停損、停利全部放進同一個大網格一次掃描，再挑出最好的一格。參數一多，網格就大到不可能看懂，最好的那一格也多半只是運氣。我們的研究改成分層進行：每一層只在上一層選出的組合上改一件事。這篇說明這些層怎麼接起來，讀策略報告時，「父策略」「研究階段」「參數鄰域」這些詞指的是什麼。

結論

一個策略分四個研究階段（Stage 0–3）長出來：第 0 階是原始訊號（Definition），濾網也屬於這一階；第 1 階在第 0 階上試延遲進場；第 2 階在第 1 階上設停損停利；第 3 階在第 2 階上加移動停損與保本。每一組的父策略，是同一個 Definition、到上一層為止設定都相同、之後都沒有設定的那一組。判斷參數是平台還是孤島時，只在同一個父策略的子策略（兄弟）之間比較，父策略本身不參與比較，而是當成基準：子策略要贏過父策略，這一層的複雜度才值得加。

以上是結論；以下每一節是一個主張的證據，可以從各節或證據連結進入策略報告，看全部參數組的數據。

策略分成哪幾層？

每一層回答一個問題，只改這個問題相關的設定，其他設定沿用父策略。文中術語的定義見量化策略研究用詞表。

研究階段（Stage）名稱回答的問題會改的設定父策略
第 0 階Definition這個訊號本身有沒有優勢？訊號條件、方向、進場時點、指標、濾網沒有（最上層）
第 1 階進場換個進場價，能不能少挨一點不利波動？延遲進場的方式與距離同一個 Definition 的原始進場
第 2 階出場停損停利該放在哪？停損（SL）、停利（TP）、時間出場選出的第 1 階那一組
第 3 階移動停損與保本走對方向之後，怎麼保住利潤？移動停損（TS）、保本停損（BE）選出的第 2 階那一組

一個具體的例子是我們的 US100 Market Profile 系列：

  • 第 0 階：開盤跌破價值區該做空嗎？比較 13 個 Market Profile 訊號，選出每個訊號的方向與進場時點；趨勢濾網該在什麼波動下擋單？比較加不加 SuperTrend × 波動濾網。加了濾網的 setup 是另一個 Definition。
  • 第 1 階：延遲進場能壓低 MAE 嗎？在每個 setup 的原始進場上，掃描有利（Favorable）、不利（Adverse）兩種延遲進場；延遲進場之後還要加趨勢濾網嗎？比較延遲進場放在有濾網與沒有濾網的 Definition 上的差別。
  • 第 2 階：停損停利該設在哪？的父策略，是加了 SuperTrend × 波動濾網的 Definition 上選出的延遲進場；用父策略的 MAE、G_MFE 設定停損停利。
  • 第 3 階：保本停損該在哪裡觸發？在上一篇選出的停損停利上，加保本停損。

每往下一層，父策略都是上一層選出來的組。

為什麼要分層，而不是一次掃完？

一次掃描所有參數，組合數是每個參數選項數的乘積。網格越大，越容易靠運氣挑到一格特別好的，結果也越難解釋：那一格好，是因為進場、因為停損，還是兩者剛好搭在一起？

分層之後，每一層只有一兩個研究變數，網格小到可以一眼看懂。哪一層讓結果變好、哪一層沒有幫助，也分得清楚。某一層找不到比父策略好的設定時，就停在父策略，不為了完整而硬加一層。

分層的代價是：上一層選錯了，下一層只會在錯的基礎上繼續往下長。所以每一層選出來的不是唯一最佳的一組，而是幾組穩健的候選。

濾網算一層嗎？

不算。濾網決定的是「哪些天有訊號」，改的是 Definition 本身，所以加了濾網的策略是另一個 Definition，和沒有濾網的原始策略並列在第 0 階，兩者是水平比較，不是父子。

加了濾網的 Definition 之後也可以往下長：它的延遲進場，父策略是加了濾網的那個原始進場，而不是沒有濾網的原始策略。換句話說，樹不是只有一棵，每個 Definition 都是一棵樹的根。

  • 原始訊號（第 0 階）
    • 延遲進場（第 1 階）→ 停損停利（第 2 階）→ 保本（第 3 階）
  • 原始訊號 ＋ 濾網（第 0 階，另一個 Definition）
    • 延遲進場（第 1 階）→ 停損停利（第 2 階）→ 保本（第 3 階）

父策略怎麼決定？

每一組的研究階段，是它有設定的最後一階：只設延遲進場是第 1 階，設了停損停利是第 2 階，加了移動停損或保本是第 3 階，什麼都沒設就是第 0 階。

父策略依三個條件找：

  1. 同一個 Definition：訊號、方向、指標、濾網都相同。
  2. 到上一層為止的設定都相同：第 2 階的父策略，延遲進場要和它一樣。
  3. 這一層和之後的設定都沒有：第 2 階的父策略不能已經有停損停利。

有兩個細節：

  • 跳過的層不算。直接在原始進場上設停損停利（沒有延遲進場），父策略就是原始進場。
  • 比較時沒有放進來的組，不會被當成父策略。這時那一組沒有父策略，報告也不會替它找一個替代。

同一個 Definition 可能在不同次回測裡出現，例如有利與不利延遲進場分兩次掃描。我們用 Definition 的內容判斷是不是同一個，而不是用回測的編號，所以分開掃描的子策略也能找到同一個父策略。

為什麼參數只和兄弟比較？

同一個父策略底下、同一層的子策略稱為兄弟。它們只有研究變數不同，其他設定全部一樣，所以兄弟之間的差異，只能歸因到研究變數。

判斷一組參數是平台還是孤島，就是看它的兄弟：延遲距離往前、往後一格，結果是不是差不多。平台代表結果不依賴剛好那一個數字；孤島代表只有那一格好，換一點就失效，多半是運氣。

如果把不同父策略的子策略放在同一張圖比較，差異就混進了訊號、方向、進場時點的不同，看不出研究變數本身的效果。而且不同 Definition 的參數組合本來就不完整，圖上會出現大片空格。

父策略本身不和兄弟並列，而是當成基準：

  • 子策略普遍比父策略好，這一層才值得加。
  • 只有一兩個子策略比父策略好，而且周圍都比父策略差，那多半是孤島。
  • 所有子策略都比父策略差，就停在父策略。

在策略報告裡怎麼看？

策略報告依這套關係組織：

  • 研究階段：多層的研究可以切換階段，每一階的參數組列出和父策略的差距。
  • 選取：可以一鍵把選取組的父策略和相鄰格加進來比較。
  • 參數鄰域：熱圖只畫同一個父策略的子策略，X、Y 是這一層的研究變數；顏色以父策略為中心，綠色優於父策略、紅色劣於。也可以改看全部父策略的中位數，檢查這一層的效果是不是普遍成立。
分層研究的限制

每一層都用同一段歷史資料選出下一層的父策略，層數越多，選擇的次數越多，結果越容易高估。子策略之間也不是獨立的嘗試：相鄰的參數組合交易大多相同。所以分層的結果仍要用沒有參與挑選的期間檢查，而且每一層只在證據足夠時才往下長。

常見問題

什麼是父策略？

父策略是同一個 Definition、到上一層為止設定都相同、這一層之後都沒有設定的那一組。延遲進場的父策略是原始進場，停損停利的父策略是選出的延遲進場，保本的父策略是選出的停損停利。

濾網為什麼不是一層？

濾網改變的是哪些天有訊號，屬於 Definition 本身。加了濾網的策略是另一個 Definition，和原始策略在第 0 階並列比較，之後再各自往下接延遲進場、停損停利與保本。

為什麼不一次掃描所有參數？

一次掃描的網格是各參數選項數的乘積，越大越容易靠運氣挑到最好的一格，也看不出是哪個設定在起作用。分層後每一層只有一兩個研究變數，可以清楚判斷這一層有沒有讓結果變好。

怎麼判斷參數是平台還是孤島？

只在同一個父策略的子策略之間比較：選出的那一組周圍的參數也都比父策略好，是平台；只有那一格好、周圍都比父策略差，是孤島。
